 COMO PUBLICAR (uma vez só):
  1. GitHub -> New repository -> nome: site-filafacil (público).
  2. Suba tudo o que está nesta pasta: index.html, CNAME e a pasta icons/.
  3. Settings -> Pages -> Source: Deploy from a branch -> main / (root).
  4. Custom domain: filafacilapp.com.br -> Save.
  5. Espere o DNS Check passar e marque "Enforce HTTPS".
